# มาร์คโย่ง – เว็บไซต์สกอร์บอร์ด วิทยาลัยเทคนิคบ้านค่าย

โครงสร้างโปรเจกต์

```
index.html            หน้าเว็บหลัก (โครง HTML)
css/style.css         สไตล์ทั้งหมด
js/                   สคริปต์ แยกตามหน้าที่ (โหลดตามลำดับใน index.html)
assets/images/       รูป (โลโก้) ที่แยกออกมาจากสไตล์เดิม
```

หมายเหตุ: ระบบเก็บข้อมูลสด (สกอร์ ตารางแข่ง ทีม ผู้ลงทะเบียน) ใช้ `claude.use('db')` และ `claude.use('user')`
ซึ่งทำงานเฉพาะบน claude.ai เมื่อนำไปโฮสต์ที่ GitHub Pages ส่วนนี้จะไม่ทำงาน ต้องเปลี่ยนไปใช้ฐานข้อมูลอื่น (เช่น Firebase)
